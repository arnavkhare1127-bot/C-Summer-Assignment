# 30-Day C Programming Practice Sheet

A structured, day-by-day set of 120 C programming problems designed to build coding fluency from the basics through interview-style projects. Each problem is tagged with the companies commonly known to ask similar questions in technical interviews (e.g., TCS, Infosys, Wipro, Amazon, Deloitte, Microsoft, Adobe, Paytm, Accenture).

## File

- `C_Programming_30Day_Programming.docx` - the full practice sheet, organized as one table per day (Day 1 - Day 30), each containing 4 questions with a problem statement and associated company tags.

## What's Inside

The 30 days are organized into progressive topic blocks:

| Days | Topics |
|------|--------|
| 1-7  | Number-based fundamentals: sums, factorials, digit operations, primes, GCD/LCM, Fibonacci, Armstrong numbers, perfect/strong numbers, bit manipulation, recursion |
| 8-10 | Pattern printing: pyramids, triangles, hollow shapes, star and number patterns |
| 11-12 | Functions: modular problem-solving using custom functions |
| 13-17 | Arrays: searching, sorting (bubble, selection, binary), duplicates, rotation, merging, unions/intersections |
| 18 | Matrices: addition, subtraction, transpose, multiplication, symmetry checks |
| 19-20 | Strings: reversal, palindrome checks, anagrams, compression, word counting, case conversion |
| 21-30 | Mini-projects: number guessing game, voting system, ATM simulation, quiz application, student/employee/library/bank management systems, and other complete console applications |

## How to Use This Sheet

1. Work through the problems **in order, one day at a time** - later days build on concepts introduced earlier (e.g., arrays before matrices, functions before larger projects).
2. For each question, write and test your own C program before checking any reference solution.
3. Use the company tags as a guide to prioritize problems if you're preparing for a specific interview.
4. Aim to complete each day's 4 questions in a single sitting to build consistency over the full 30 days.

## Prerequisites

- A C compiler (e.g., GCC) or an online IDE such as [OnlineGDB](https://www.onlinegdb.com/) or [Compiler Explorer](https://godbolt.org/).
- Basic familiarity with C syntax (variables, loops, and conditionals) is helpful but not required - Day 1 starts from fundamentals.

## Goal

By the end of the 30 days, you should be comfortable with core C programming concepts - control flow, functions, arrays, matrices, strings, and basic data structures - and have hands-on experience building small, complete console applications, preparing you for technical interview rounds at both product and service-based companies.
